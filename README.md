# Giulio Dajani — personal site

## Before publishing (10 minutes)
1. **Domain**: buy `giuliodajani.com` (or `.co.uk` / `.dev`) and replace every `giuliodajani.com` in `index.html`, `robots.txt` and `sitemap.xml` if yours differs.
2. **Profiles**: search `index.html` for `TODO` and paste your real LinkedIn and GitHub URLs (they appear in both the schema `sameAs` list and the Contact buttons). Add any other profiles too: ORCID, Google Scholar, and the VerifAI GitHub repo.
3. **Photo**: add a clear headshot named `photo.jpg` (square, at least 800px). Google needs an image to build a profile panel.
4. **CV**: add your CV as `cv.pdf`. **Remove your phone number first.** This file will be public.

## Hosting (free)
- **GitHub Pages**: create a repo, upload these files, go to Settings → Pages → deploy from `main`, then set your custom domain.
- **Netlify / Cloudflare Pages**: drag and drop this folder, then connect your domain.

## After it's live
- Add the site to **Google Search Console**, verify it, and submit `sitemap.xml`.
- Check the schema with Google's **Rich Results Test** (search.google.com/test/rich-results).
- Put the site URL on LinkedIn, GitHub, your email signature, and the VerifAI repo/paper.
- When the VerifAI paper is published, add the DOI to the page and to the schema (`sameAs` or a `ScholarlyArticle`).
